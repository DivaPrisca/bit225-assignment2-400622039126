## Description
BlueLib Catalogue is a responsive single-page front-end for the BlueCrest College Library.

## Technologies
- HTML5
- CSS3
- Vanilla JavaScript

## Features
1. Displays six initial books from a JavaScript array.
2. Searches books by title as the user types.
3. Filters books by category.
4. Adds new books without reloading the page.
5. Validates the Add Book form.
6. Provides a Borrow button that reduces available copies.
7. Disables Borrow and displays "Out of stock" when copies reach zero.
8. Uses responsive CSS Grid for desktop, tablet, and mobile layouts.
